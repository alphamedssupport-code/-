# LINE 丸投げ集客サービス 提案書

**不動産会社向け / 自動リード獲得・育成ソリューション**

---

## 1. エグゼクティブサマリー

本サービスは、LINE公式アカウントを活用した**完全自動の顧客集客・育成システム**です。  
不動産会社様は初期設定をお任せいただくだけで、24時間365日、見込み客の発掘・ヒアリング・選別・担当者へのエスカレーションまでをすべて自動で行います。

> **「集客は丸投げ。担当者は商談だけに集中できる。」**

## 3. サービス概要

### 3.1 何をするサービスか

LINE公式アカウントに友だち追加した見込み客に対し、**自動シナリオが会話形式でヒアリングを行い、温度感の高いリードのみを担当者に通知する**サービスです。

```
見込み客がLINE友だち追加
        ↓
自動ウェルカムメッセージ送信
        ↓
問い合わせ種別をクイックリプライで選択
  ├─ 購入希望 → 購入フロー（エリア・予算・時期を自動収集）
  ├─ 売却希望 → 売却フロー（物件情報・売却時期を自動収集）
  └─ 賃貸希望 → 賃貸フロー（エリア・家賃・入居時期を自動収集）
        ↓
リードスコアリング（優先度：高 / 中 / 低）
        ↓
担当者にLINEで即時通知（スコアと収集情報つき）
        ↓
自動フォローアップシーケンス開始（Day1/3/7/14）
```

### 3.2 対応する問い合わせ種別

| 種別 | 自動収集する情報 |
|------|-----------------|
| **購入希望** | 希望エリア / 予算帯 / 購入時期 / 物件種別 |
| **売却希望** | 物件所在地 / 物件種別 / 売却時期 / 現在の状況 |
| **賃貸希望** | 希望エリア / 月額家賃 / 入居希望時期 / 間取り |

## 4. 主要機能

### 4.1 自動シナリオ（LINE Messaging API）

- **ウェルカムフロー**: 友だち追加時に即座にFlexメッセージで歓迎・種別選択
- **ヒアリングフロー**: クイックリプライによる選択式で入力負荷ゼロ
- **フォールバック処理**: 想定外の入力にも自然な返答でフロー維持
- **24時間自動対応**: 深夜・休日でも即時レスポンス

### 4.2 リードスコアリング

見込み客の回答内容をもとに自動スコアリングし、担当者の対応優先度を決定します。

| スコア | 優先度 | 通知方法 |
|--------|--------|----------|
| 80点以上 | 高（HOT） | 即時LINE通知 + アラート |
| 50〜79点 | 中（WARM） | 即時LINE通知 |
| 49点以下 | 低（COLD） | 日次バッチ通知 |

**スコアリング基準例（購入希望）:**
- 購入時期が3ヶ月以内 → +40点
- 予算が明確 → +30点
- 希望エリアが明確 → +20点
- 物件種別が決まっている → +10点

### 4.3 担当者への自動通知

見込み客のスコアと収集した情報を、Flex Messageカードで担当者のLINEに即時送信します。

```
┌─────────────────────────────┐
│  🏠 新規リード通知 [HOT]     │
├─────────────────────────────┤
│  名前: 田中 様              │
│  種別: 購入希望             │
│  エリア: 東京都世田谷区      │
│  予算: 5,000万円台          │
│  時期: 3ヶ月以内            │
│  スコア: 90点               │
├─────────────────────────────┤
│  [LINE で返信する]  [電話]   │
└─────────────────────────────┘
```

### 4.4 自動フォローアップ（ナーチャリング）

ヒアリング完了後、以下のスケジュールで自動メッセージを配信します。

| タイミング | 購入希望者向けメッセージ例 |
|-----------|--------------------------|
| Day 1 | 「ご希望の物件情報をピックアップしました」 |
| Day 3 | 「〇〇エリアの相場情報をお届けします」 |
| Day 7 | 「お役立ち情報：住宅ローンのポイント」 |
| Day 14 | 「内見のご予約はお決まりですか？」 |

### 4.5 担当者ルーティング

エリア・物件種別ごとに担当者を自動割り当て。複数拠点・複数担当者にも対応。

## 9. よくある質問

**Q. LINE公式アカウントを持っていなくても導入できますか？**  
A. はい。アカウント開設から代行いたします。

**Q. 既存のLINE公式アカウントに追加できますか？**  
A. はい。既存アカウントへの組み込みに対応しています。

**Q. シナリオの内容をカスタマイズできますか？**  
A. はい。貴社のターゲットや物件種別に合わせてシナリオをカスタマイズします。

**Q. 個人情報の取り扱いは安全ですか？**  
A. LINE Messaging APIの公式SDKを使用し、取得データは暗号化して保管します。個人情報保護法に準拠した運用を行います。

**Q. 解約はいつでもできますか？**  
A. はい。月単位での契約で、いつでも解約可能です。
